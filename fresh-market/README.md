# Свежий Маркет

Адаптивный каталог магазина на HTML, CSS и обычном JavaScript. Есть карточки товаров, подробная страница с галереей, характеристиками и отзывами, корзина, поиск, категории, сортировка, добавление, редактирование и удаление. Фреймворки, сборщик и установка npm-пакетов не нужны.

## Запуск
hhhghghg
Нужен Python 3 и современный браузер.

**В Windows откройте папку `fresh-market` и дважды нажмите `start.cmd`.** Откроется окно сервера, а затем магазин в браузере. В следующий раз повторите тот же шаг.

Не закрывайте окно сервера, пока пользуетесь сайтом. Для остановки нажмите в нём `Ctrl+C` или закройте окно. Обычно магазин открывается по адресу **http://127.0.0.1:8000/**. Если этот порт занят, запуск автоматически выбирает свободный: актуальный адрес указан в окне сервера и открывается в браузере. Если браузер не открылся, скопируйте туда указанный адрес.

Можно запустить тот же помощник из терминала в папке `Project`:

```powershell
python fresh-market/start_server.py
```

Для запуска без автоматического открытия браузера добавьте `--no-browser`. Другой предпочтительный порт можно выбрать через `--port 8001`. В Windows вместо `python` можно использовать `py -3`.

Альтернативный ручной запуск из папки `Project`:

```powershell
cd fresh-market
python -m http.server 8000 --bind 127.0.0.1
```

При ручном запуске откройте **http://127.0.0.1:8000/**. Если терминал уже открыт в папке `fresh-market`, выполняйте только вторую команду. Если порт 8000 занят, укажите другое число и откройте адрес с этим портом.

Оставьте терминал открытым, пока пользуетесь сайтом. Для остановки сервера нажмите `Ctrl+C`. Не открывайте `index.html` двойным щелчком: JavaScript-модулям нужен HTTP-сервер. Для загрузки товаров, их фотографий и запросов к API требуется интернет.

Если используете Live Server, откройте `fresh-market/index.html` через **Open with Live Server**. Адрес страницы должен начинаться с `http://` или `https://`, а не с `file://`.

При открытии двойным щелчком сайт показывает инструкцию запуска вместо бесконечного индикатора. Ошибка загрузки скриптов также выводится на странице; ожидание запуска ограничено 25 секундами, ожидание ответа API — 15 секундами.

## Как пользоваться

- Откройте товар нажатием на его фотографию, название, свободную область карточки или кнопку «Подробнее». Назад можно вернуться кнопкой «Назад к каталогу» или средствами браузера.
- Введите название в строку поиска. Поиск, выбранная категория и сортировка работают совместно.
- Для добавления нажмите «Добавить товар», заполните форму и сохраните её. Ошибки отображаются рядом с полями.
- Кнопки редактирования и удаления на карточке работают независимо от перехода на страницу товара. Удаление требует подтверждения.
- Кнопками «−» и «+» в карточке можно изменять остаток на складе. Отрицательные остатки не допускаются.
- На подробной странице доступны дополнительные фотографии, сведения из API и похожие товары той же категории.

## Корзина

- Нажмите «В корзину» на карточке или подробной странице товара. Откройте корзину кнопкой в шапке сайта.
- В корзине можно менять количество кнопками «−» и «+», удалять отдельные позиции и очищать всю корзину. Сумма пересчитывается автоматически.
- Количество в корзине ограничено остатком на складе. Добавление в корзину само по себе не уменьшает складской остаток.
- Если товар удалён из каталога, он исчезает и из корзины. При уменьшении складского остатка количество в корзине корректируется; изменение цены обновляет сумму.
- Корзина хранится в памяти до перезагрузки страницы. Переходы между каталогом, товарами и корзиной сохраняют выбранные позиции. Оплата и оформление заказов не предусмотрены.

## Данные и ограничения

**Изменения товаров и корзина хранятся только в памяти JavaScript до перезагрузки страницы.** Переходы внутри сайта их сохраняют; перезагрузка вкладки возвращает исходный каталог и очищает корзину.

Все товары загружаются одним запросом `GET https://dummyjson.com/products?limit=0`. При первом открытии видны все категории, а сортировка «Сначала продукты» помещает продукты питания в начало каталога. Выбрать отдельную категорию можно через фильтр. DummyJSON содержит также непродовольственные товары. После CRUD-операций каталог повторно не загружается.

Запросы выполняются с помощью `fetch`:

| Операция                    | Метод и адрес           |
| --------------------------- | ----------------------- |
| Получить каталог            | `GET /products?limit=0` |
| Добавить товар              | `POST /products/add`    |
| Изменить существующий товар | `PATCH /products/{id}`  |
| Удалить существующий товар  | `DELETE /products/{id}` |

Базовый адрес — `https://dummyjson.com`. API имитирует запись и не сохраняет изменения на сервере. Новые товары получают уникальные строковые локальные ID, которые не пересекаются с числовыми ID API. Дальнейшее редактирование и удаление таких товаров выполняется только в памяти, без запроса к серверу. Если запрос не удался, сайт сообщает об ошибке.

Показатели в шапке относятся ко всему текущему каталогу. Общая стоимость склада считается как сумма `цена × остаток` для всех товаров. API не указывает валюту: USD используется как условный формат отображения исходных чисел, без конвертации. Сведения о весе и размерах выводятся без выдуманных единиц измерения. В характеристиках показываются только доступные данные API; у нового товара нет искусственно созданных рейтингов и отзывов. Интерфейс русскоязычный; известные названия и описания продуктов, а также типовые отзывы API переведены на русский. Перевод названий и описаний применяется только при первоначальной загрузке, поэтому введённый пользователем текст сохраняется без изменений. Остальной текст API отображается в оригинале.

Это учебная демонстрация интерфейса магазина. Оплата, оформление реальных заказов, авторизация и постоянное хранение на сервере не реализованы.

## Задачи команды

Откройте `tasks.html` через локальный сервер или нажмите **Задачи** в меню магазина. Установка npm-пакетов и сборка не требуются.

- Список задач загружается из DummyJSON. У каждой задачи есть `userId`; автор видимых задач запрашивается отдельным GET по этому ID. Повторные запросы одного автора используют общий кэш.
- Нажмите на ник автора: справа откроется профиль примерно на половину экрана. На телефоне окно занимает всю ширину. В профиле есть имя, ник, контакты, адрес, возраст, образование, работа и задачи пользователя.
- Поиск работает по тексту задачи, ID, нику и имени. Фильтры по автору и статусу сочетаются с сортировкой по ID, названию, автору или выполнению. Большой список разбит на страницы по 10 задач.
- В задачах профиля доступны отдельные поиск, статус и сортировка. Кнопка **В общем списке** применяет фильтр выбранного автора к основной странице.
- Галочка меняет статус. Кнопка **Новая задача** создаёт запись; карандаш открывает редактирование, корзина — подтверждение удаления.
- Окна закрываются кнопкой, клавишей Escape или нажатием на затемнённую область. Во время сохранения закрытие формы блокируется. Ошибки выводятся рядом с формой либо внутри профиля.

### Запросы к API

| Действие | Запрос |
| --- | --- |
| Все задачи | `GET /todos?limit=0` |
| Список авторов для поиска и выбора | `GET /users?limit=0&select=id,username,firstName,lastName,image` |
| Полный профиль автора по userId | `GET /users/{userId}` |
| Задачи автора | `GET /todos/user/{userId}?limit=0` |
| Создание | `POST /todos/add` |
| Изменение текста, автора или статуса | `PATCH /todos/{id}` |
| Удаление | `DELETE /todos/{id}` |

Базовый адрес — `https://dummyjson.com`. Документация: [задачи](https://dummyjson.com/docs/todos), [пользователи](https://dummyjson.com/docs/users).

DummyJSON имитирует операции записи и не сохраняет их на сервере. После успешного ответа изменения сохраняются в `localStorage` этого браузера под ключом `fresh-market.tasks.v1`. Новые записи получают уникальные локальные ID, поэтому несколько созданных задач не конфликтуют. Изменения локальных записей выполняются в браузере. Они сохраняются после перезагрузки, но не переносятся между устройствами или адресами/портами сервера.

### Файлы раздела

- `tasks.html` — разметка страницы и окон.
- `tasks.css` — оформление и адаптация к ширине экрана.
- `src/tasksApi.js` — HTTP-запросы, тайм-ауты, проверка ответов и кэш авторов.
- `src/tasksModel.js` — совместные фильтры, сортировки и сохранённые изменения.
- `src/tasksApp.js` — список задач, профиль автора, формы и обработчики событий.

### Запуск без Python

`start.cmd` сначала пробует Python 3, затем Node.js. Если Python не установлен, но доступен Node.js, используется `start_server.cjs` без сторонних пакетов. В терминале можно выполнить `node start_server.cjs`; для другого порта — `node start_server.cjs --port 8001`. Параметр `--no-browser` отключает автоматическое открытие браузера. Адреса магазина и задач выводятся в терминале.
