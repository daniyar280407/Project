## 3 және 4 тапсырмалар

`index.html` файлын браузерде ашыңыз.

- **3 тапсырма:** жолдар мен бағандар санын (1–50) енгізіп, «Кесте құру» батырмасын басыңыз. `createTable(rows, columns)` функциясы кестені құрады. Бояу түсін таңдаған соң ұяшықты басыңыз; сол түспен қайта басу бояуды өшіреді. Басқа түсті таңдап басу ұяшықты қайта бояйды.
- **Санау:** есептелетін түсті таңдаңыз. `countCellsByColor(color)` функциясы `red`, `blue`, `green`, `yellow` немесе `empty` түстеріндегі ұяшықтар санын қайтарады. Нәтиже бояғанда, түс таңдағанда және «Ұяшықтарды санау» батырмасын басқанда жаңарады. Жаңа кесте құрғанда бояулар тазаланады.
- **4 тапсырма:** сайттың жоғарғы жағындағы қосқыш ашық және қараңғы тақырыптарды ауыстырады. `setTheme(theme)` функциясы бүкіл сайттың режимін өзгертеді. Таңдау `localStorage` арқылы сақталады; сақтау қолжетімсіз болса да қосқыш жұмыс істейді.
