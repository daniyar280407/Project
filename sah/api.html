    Подсказка для ответа преподавателю
    
      
    CRUD: Create — POST, Read — GET, Update — PUT/PATCH, Delete — DELETE.
    
      
    Группы статусов: 1xx — информация, 2xx — успех, 3xx — перенаправление/кеш, 4xx — ошибка клиента, 5xx — ошибка сервера.
    
      
    200 — успешно; 201 — создано; 400 — неверный запрос; 401 — нужна авторизация; 403 — доступ запрещён; 404 — не найдено; 500 — ошибка сервера.
