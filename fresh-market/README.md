# Свежий Маркет

Адаптивный каталог магазина на HTML, CSS и обычном JavaScript. Есть карточки товаров, подробная страница с галереей, характеристиками и отзывами, поиск, категории, сортировка, добавление, редактирование и удаление. Фреймворки, сборщик и установка npm-пакетов не нужны.

## Запуск

Нужен Python 3 и современный браузер. Откройте терминал в корневой папке репозитория `Project` и выполните:

```powershell
cd fresh-market
python -m http.server 8000
```

Откройте **http://localhost:8000**. Если терминал уже открыт в папке `fresh-market`, выполняйте только вторую команду. В Windows, если команда `python` не найдена, попробуйте `py -m http.server 8000`.

Оставьте терминал открытым, пока пользуетесь сайтом. Для остановки сервера нажмите `Ctrl+C`. Не открывайте `index.html` двойным щелчком: JavaScript-модулям нужен HTTP-сервер. Для загрузки товаров, их фотографий и запросов к API требуется интернет.

Если используете Live Server, откройте `fresh-market/index.html` через **Open with Live Server**. Адрес страницы должен начинаться с `http://` или `https://`, а не с `file://`.

При открытии двойным щелчком сайт показывает инструкцию запуска вместо бесконечного индикатора. Ошибка загрузки скриптов также выводится на странице; ожидание запуска ограничено 25 секундами, ожидание ответа API — 15 секундами.

## Как пользоваться

- Откройте товар нажатием на его фотографию, название, свободную область карточки или кнопку «Подробнее». Назад можно вернуться кнопкой «Назад к каталогу» или средствами браузера.
- Введите название в строку поиска. Поиск, выбранная категория и сортировка работают совместно.
- Для добавления нажмите «Добавить товар», заполните форму и сохраните её. Ошибки отображаются рядом с полями.
- Кнопки редактирования и удаления на карточке работают независимо от перехода на страницу товара. Удаление требует подтверждения.
- Кнопками «−» и «+» в карточке можно изменять остаток на складе. Отрицательные остатки не допускаются.
- На подробной странице доступны дополнительные фотографии, сведения из API и похожие товары той же категории.

## Данные и ограничения

**Изменения хранятся только в памяти JavaScript до перезагрузки страницы.** Переходы между каталогом и подробными страницами их сохраняют; перезагрузка вкладки возвращает исходный каталог.

Все товары загружаются одним запросом `GET https://dummyjson.com/products?limit=0`. При первом открытии видны все категории, а сортировка «Сначала продукты» помещает продукты питания в начало каталога. Выбрать отдельную категорию можно через фильтр. DummyJSON содержит также непродовольственные товары. После CRUD-операций каталог повторно не загружается.

Запросы выполняются с помощью `fetch`:

| Операция                    | Метод и адрес           |
| --------------------------- | ----------------------- |
| Получить каталог            | `GET /products?limit=0` |
| Добавить товар              | `POST /products/add`    |
| Изменить существующий товар | `PATCH /products/{id}`  |
| Удалить существующий товар  | `DELETE /products/{id}` |

Базовый адрес — `https://dummyjson.com`. API имитирует запись и не сохраняет изменения на сервере. Новые товары получают уникальные строковые локальные ID, которые не пересекаются с числовыми ID API. Дальнейшее редактирование и удаление таких товаров выполняется только в памяти, без запроса к серверу. Если запрос не удался, сайт сообщает об ошибке.

Показатели в шапке относятся ко всему текущему каталогу. Общая стоимость склада считается как сумма `цена × остаток` для всех товаров. API не указывает валюту: USD используется как условный формат отображения исходных чисел, без конвертации. Сведения о весе и размерах выводятся без выдуманных единиц измерения. В характеристиках показываются только доступные данные API; у нового товара нет искусственно созданных рейтингов и отзывов. Интерфейс русскоязычный; известные названия и описания продуктов, а также типовые отзывы API переведены на русский. Перевод названий и описаний применяется только при первоначальной загрузке, поэтому введённый пользователем текст сохраняется без изменений. Остальной текст API отображается в оригинале.

Это учебная демонстрация интерфейса магазина. Оплата, оформление реальных заказов, авторизация и постоянное хранение на сервере не реализованы.

## Файлы

```text
fresh-market/
├── index.html              # Структура страницы и модальные окна
├── styles.css              # Оформление и адаптивная сетка
├── src/
│   ├── app.js              # Состояние, каталог, страница товара и CRUD
│   ├── productsApi.js      # HTTP-запросы к DummyJSON
│   └── productTranslations.js # Переводы известных текстов API
├── assets/
│   ├── hero-market.jpg     # Фотография для главного баннера
│   ├── placeholder.svg     # Заглушка недоступной фотографии
│   └── favicon.svg         # Иконка сайта
└── README.md
```
