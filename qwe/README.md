# Свежий Маркет

Локальный учебный сайт для управления товарами: HTML, CSS и обычный JavaScript с ES-модулями. Фреймворки, npm и сборка не нужны.

## Установка и запуск

1. Сохраните всю папку проекта, сохранив подпапку src.
2. Для запуска нужен Python 3. Если Python ещё не установлен, установите его с https://www.python.org/downloads/.
3. Откройте терминал в папке fresh-market, где лежит index.html.
4. Запустите локальный HTTP-сервер:

```powershell
py -m http.server 8000
```

Если команда py недоступна:

```powershell
python -m http.server 8000
```

Откройте http://localhost:8000 в браузере. Для остановки сервера нажмите Ctrl+C.

Запускайте страницу через HTTP-сервер: открытие index.html двойным щелчком может блокировать загрузку JavaScript-модулей. Для получения товаров и фотографий нужен интернет. Если порт 8000 занят, укажите другой порт, например 8001, и откройте http://localhost:8001.

## Файлы

- index.html — структура страницы, карточки и модальные окна.
- styles.css — оформление и адаптация к телефону.
- src/app.js — состояние каталога, поиск, фильтры, сортировка, проверка формы и CRUD.
- src/productsApi.js — fetch-запросы к DummyJSON.
- README.md — эта инструкция.

## Возможности

- Полный каталог с фотографией, названием, ценой, категорией, брендом, рейтингом и остатком.
- Поиск по названию без учёта регистра, фильтр по категории и сортировка по названию, цене или рейтингу.
- Добавление и редактирование через форму; удаление только после подтверждения.
- Изменение названия, цены, категории, бренда, описания и остатка.
- Быстрые кнопки + и − для остатка на складе; количество не может стать отрицательным.
- Состояния загрузки, ошибки, пустого каталога и отсутствия результатов поиска.
- Проверка формы: непустое название, положительная конечная цена и неотрицательное целое количество.
- Общие показатели всего каталога: количество товаров, число разных категорий и сумма price × stock. Поиск и фильтры меняют только отображаемые карточки и счётчик «Показано».
- Изменения применяются только после успешного запроса; при ошибке данные остаются прежними.

## Как хранятся изменения

DummyJSON имитирует операции и не сохраняет их постоянно. Приложение хранит изменения в памяти текущей страницы. Поиск, фильтры, сортировка и перерисовка сохраняют добавленные, изменённые и удалённые товары.

После перезагрузки или закрытия страницы изменения сбрасываются: каталог заново загружается из API. LocalStorage и собственная база данных не используются.

Каждый успешный POST добавляет в память товар с уникальным ID local-1, local-2 и так далее. ID из ответа POST игнорируется, потому что API может возвращать один и тот же ID для разных добавлений. После удаления локального товара его ID не используется снова. Редактирование и удаление локальных товаров, включая изменение остатка, выполняются без сетевого запроса.

Для исходных товаров сначала выполняется PATCH или DELETE. После успеха в памяти применяются только отправленные изменения: полный ответ DummyJSON может содержать старые значения и не должен перезаписывать предыдущие правки.

## Учебные данные и цены

Интерфейс и названия категорий — на русском. Названия, бренды и описания исходных товаров приходят из API и сохраняются в исходном виде, часто на английском. Создавайте собственные товары на русском через форму.

Цены API указаны в долларах США (USD). Каталог DummyJSON содержит не только продукты питания, но и другие учебные категории. Чтобы увидеть продукты, выберите категорию «Продукты питания».

Новые товары не имеют фотографии и оценок: карточка показывает «Нет фото» и «Нет оценок».

## HTTP-запросы

Базовый адрес: https://dummyjson.com.

| Действие | Метод | Путь |
| --- | --- | --- |
| Загрузить полный каталог | GET | /products?limit=0 |
| Добавить товар | POST | /products/add |
| Изменить исходный товар | PATCH | /products/{id} |
| Удалить исходный товар | DELETE | /products/{id} |

Документация: https://dummyjson.com/docs/products
